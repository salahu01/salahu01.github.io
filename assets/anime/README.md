# Anime cover images

Drop an image here to replace the drawn cover on the anime wall: `.jpg`, `.jpeg`, `.png` or `.webp`, any shape.
It is cropped to a square automatically: centred left to right, and for tall images the upper part (where faces and titles usually are) is kept.
Use the file names below with any of those extensions, e.g. `one-piece.webp`. Any cover without an image keeps its original drawn design.
